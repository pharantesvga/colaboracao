🛡️ Lembrete do Fluxo Colaborativo

1. Ninguém comita na main

Crie sua branch: git switch -c feature/sua-tarefa (ou checkout -b).

2. Abra um Pull Request

Envie com git push e abra o PR no GitHub.

3. Revisão Cruzada Obrigatória

Pedro aprova o PR do Gustavo e vice-versa antes do merge.
